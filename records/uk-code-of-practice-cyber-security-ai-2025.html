Summary

A voluntary Code of Practice setting baseline cyber security requirements for AI systems, including generative AI, against AI-specific risks such as data poisoning, model obfuscation and indirect prompt injection. Its 13 principles span five lifecycle phases, from secure design to secure end of life, and assign provisions to developers, system operators and data custodians, among them capabilities for human oversight, security testing before release and deployment, monitoring of system behaviour, and incident management and recovery plans. It is meant as the basis of a global ETSI standard.

Status notes

Published with an implementation guide that DSIT commissioned and that DSIT and NCSC officials reviewed. The Code is an addendum to the Software Code of Practice and builds on the NCSC's Guidelines for Secure AI Development of November 2023; 80% of respondents to DSIT's call for views, held from 15 May to 9 August 2024, endorsed the intervention. DSIT, with the NCSC, will submit the Code and the guide to ETSI as the basis for a new global standard (TS 104 223) and implementation guide (TR 104 128), and the government will update the Code to mirror the ETSI standard.
